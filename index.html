Equations

Model: τ dy/dt + y = Kx

Step: y(t) = KA(1 − e−t/τ)

Ramp: y(t) = Ka[t − τ(1 − e−t/τ)]

Assumes initial output y(0) = 0 and input x(t) = A for a step or x(t) = at for a ramp.
